The test verifies saved role IDs, inherited user role labels, and preservation
of explicit user bindings. AEP's separate real-service E2E checks actual
authorization and revocation. Deploy the linked AEP default-role PR before
this console change; the existing published SDK transparently transports the
additive field and the pinned dependency is unchanged.
