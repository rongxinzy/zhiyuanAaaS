截图为新增角色的未保存表单；没有使用虚构权限、账号、密码或密钥。

权限区采用 Ant Design Tree，按全部权限、权限类型、具体权限三级缩进。
具体权限名称来自中英文 i18n，右侧操作标识使用 Ant Design 次级文本；窄屏允许自然换行。
已验证父级全选与取消、子级半选、权限区独立滚动、窄屏长文本换行及保存按钮可见。
使用独立临时角色验证真实 API 创建与编辑回填，提交仅包含具体权限 ID；验收后已删除临时角色。
