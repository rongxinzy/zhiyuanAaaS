# 模型参考价格设置验收

入口：模型网关 → 模型列表 → 对应模型的“价格设置”。用量与错误观测的成本区域也提供跳转入口。

截图使用独立、可销毁的本地 AEP Control Service + PostgreSQL，实际调用价格 GET/PUT API。
模型、账号和参考价均为临时测试数据，没有供应商凭据，也未调用真实模型。

- [深色桌面](dark.png)
- [392px 窄屏](narrow.png)

表单沿用根 Ant Design ConfigProvider 的主题和组件；包含币种、每百万 Token 的输入与输出单价、可选缓存命中输入单价、来源说明。价格以十进制字符串保存，明确区分未配置与免费（0）。

浏览器验收还覆盖非法价格、保存后刷新恢复、并发冲突与重新加载、清除确认、键盘 Select 和真实只读账号。服务端测试覆盖持久化、重启、部署隔离和并发版本。

保存参考价格不会生成成本指标、重算历史成本或发布价格到网关。成本统计仍需要网关或计费插件的可信数据来源。后端需先部署对应模型价格接口；旧服务会显示升级提示并禁用保存。

运行：设置 `ZHIYUAN_AEP_BASE_URL`、`ZHIYUAN_AEP_ADMIN_PASSWORD`（以及非默认部署/账号对应环境变量），执行 `npm run verify:admin:pricing:e2e`。可用 `ZHIYUAN_CHROME_PATH` 指定 Chrome/Chromium。测试仅应连接允许创建并删除临时模型、角色和用户的验收环境。
