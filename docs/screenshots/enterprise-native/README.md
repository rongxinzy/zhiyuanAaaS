# Native Enterprise Settings Preview

These screenshots use the real Zhiyuan host settings shell, renderer frame, and active theme stylesheet with the built enterprise UI. Session and model catalog data are synthetic. They are local browser previews, not screenshots of an installed production desktop package.

- `enterprise-account-native.png`: account settings, light theme.
- `enterprise-models-native.png`: managed model list, light theme.
- `enterprise-models-native-dark.png`: managed model list, dark theme.
- `enterprise-account-native-narrow.png`: account settings at a narrow viewport.

The account and model content has no outer floating card, nested card, shadowed container, or duplicated page title. Appearance follows the host's allowlisted Zhiyuan theme tokens. Theme updates preserve the existing iframe and password draft.
