# 知识库人工验收清单

关联 [Issue #158](https://github.com/rongxinzy/zhiyuanAaaS/issues/158) 与 [PR #165](https://github.com/rongxinzy/zhiyuanAaaS/pull/165)。这是测试操作说明，不替代产品需求或自动化验收报告。

## 开始前

本清单不表示部署已经完成。先核对交付时提供的访问地址、AaaS / Governance / WeKnora / DocReader / MCP / runtime / operator 的源码与运行版本。只刷新网页、pull 源码或重启旧镜像，都不等于更新这些组件。

使用管理员和两个独立普通用户 A、B。只创建 `kb-qa-日期-自选后缀` 命名的测试库、资料和测试员工；不要改现有业务资料、授权、模型或员工。给 A 授权一个测试库，B 不授权；测试员工显式绑定该库。管理员登录页面正常，不代表普通用户的权限测试已通过。

在 TXT、PDF 和手动文本中各放一个唯一英文数字标记，例如 `KBQA_TXT_001`，便于判断来源和检索结果。PDF 内容应能选择文字；图片解析是否可用需单独检查。URL 测试使用不含敏感信息、解析服务可访问的公开 HTTPS 静态页面，不使用 localhost、内网、云元数据地址或带凭据链接。

## 建议按这个顺序测试

| 项目 | 怎么操作 | 预期结果 |
| --- | --- | --- |
| 原生入口 | 登录知远，打开“知识库” | 页面留在知远，不跳到 WeKnora，不要求第二次登录 |
| 新建与编辑 | 分别新建文档库、FAQ 库；修改名称和描述，再刷新 | 类型正确；字段保存后仍在；操作编号可追溯 |
| 文件导入 | 文档库中上传合成 TXT、PDF；等待解析状态结束 | “文件已受理”不是成功终点；完成后分块含各自唯一标记 |
| 文本与 URL | “手动录入”合成文本；“导入 URL”公开合成页面 | 解析真正完成，来源与内容正确；失败或超时有明确状态，不冒充成功 |
| 来源和下载 | 打开“分块与来源”、预览、原文件下载；翻页 | 来源属于当前库与资料；文件内容正确；无脚本执行或内部凭据曝光 |
| 图片 | 打开含合成图片的 PDF 来源 | 正常图片可见；图片读取同样受资料权限约束，不因知道链接就可越权 |
| 分类与批量 | 创建标签；选测试资料设置标签、移动文件夹；刷新 | 名称、归属与分类持久保存；仅所选测试资料被修改 |
| FAQ | 在 FAQ 库新建问题和答案；修改、设置及清空标签、启停 | 操作在知远完成；刷新后仍正确；答案中的换行保留 |
| 分块修改 | 保存原文不变一次，再改一段文本或启停分块 | no-op 不无故涨版本；真正变化能读回；索引失败不被显示为全部成功 |
| 检索 | 在“检索与来源”选择已绑定员工，查询唯一标记 | 返回对应测试资料，点击来源能读到同一资料，不混入其他库 |
| 资料启停 | 停用已命中资料后再次检索；随后重新启用 | 停用资料不再命中；重新启用后可恢复，不因旧索引继续泄露停用内容 |
| 用户隔离 | 用普通用户 A、B 分别访问同一测试员工，查询并读取来源/下载/图片 | A 在被授权范围内可用；B 被拒绝。不能把未登录 401 算作已登录用户越权测试通过 |
| 撤权 | 保持 A 的旧登录/对话不退出；管理员撤销授权，再用 A 查询与读来源 | 旧会话也立即被拒绝，不需重新登录才能生效 |
| 员工范围 | 保留 A 授权，但将测试员工绑定设置为空 | 该员工不再检索此库；空绑定不能退化为全库 |
| 删除保护 | 测试员工仍绑定库时尝试删除库；再显式解绑后删除 | 绑定时拒绝删除；不得自动清空员工范围来强行删除；解绑后可正常删除 |
| 解析取消 | 对仍在处理的自有测试资料执行“取消解析”，刷新；按允许状态重试 | 取消状态来自服务端；不得只关闭弹窗就声称取消；重试与索引结果可核对 |
| 审计 | “日志”中打开“知识审计”，按操作人或操作编号查询 | 真实操作者、资源和结果匹配；处理中/不确定结果不伪装成成功 |
| 页面状态 | 快速切库、翻页、重复查询，切换明暗主题，缩窄窗口 | 旧请求不覆盖新库数据；按钮不永久转圈；无重复提交、遮挡或不可操作控件 |

普通用户可能没有管理员知识管理页面，这是管理权限边界。用户检索隔离请通过其可访问的测试员工对话或受控员工 API 验证，不给普通用户临时授予管理员来完成测试。

对于处理极快的小文件，“取消解析”可能来不及出现。这不是取消能力通过的证据；需要在专用隔离验收环境中使用可控处理任务测试，不能为此阻塞现有生产解析服务。

## 报 bug 时记录什么

- 页面入口、操作步骤、预期结果、实际结果，以及是否稳定复现。
- 发生时间、当前交付版本、账号类型（管理员/A/B），不要提供密码或 token。
- 测试库/资料/员工 ID、操作编号；截图保留错误提示和页面状态。
- 如查看浏览器 Network，只记录请求路径、方法、HTTP 状态、脱敏错误代码和操作编号。不要粘贴 Authorization、Cookie、完整 HAR、签名下载链接或业务正文。

出现“结果不确定”时先记录操作编号并查询审计，不立即重复上传/删除。不要通过关掉权限校验、改 Secret 或直接删除数据库来排障。

## 清理

只清理本次命名的测试员工、授权、资料与库。先确认 ID 和名称一致、员工已显式解绑，再删除库。不要清空已有知识库或删除 PVC。无法确认归属或删除结果不确定时，保留现场并报告。
