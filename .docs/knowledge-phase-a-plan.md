Node.js 24 下执行 `npm run verify:knowledge:api`。验证器只接受服务端环境变量，不使用浏览器、管理账号密码或本地凭据文件：

| 环境变量 | 含义 |
| --- | --- |
| `ZHIYUAN_KNOWLEDGE_BASE_URL` | 上游 API 根地址，不含 `/api/v1`；允许 HTTPS 或本机 loopback HTTP；可以有反向代理路径前缀 |
