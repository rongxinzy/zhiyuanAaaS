# Repository Guidance

- This repository contains the closed Zhiyuan enterprise extension.
- Product names, documentation, logs, and identifiers must use Zhiyuan.
- Keep private implementation outside the public application repository.
- Pin every public core and AEP SDK input to an immutable version or commit.
- Do not add UI without first reading this repository's `DESIGN.md` (the web admin console adaptation of the public application's design standard).
- Commit messages and pull request titles must follow Conventional Commits.
